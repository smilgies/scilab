Never say never! Fooling around with my little Raspberry Pi 5 with only 2 GB RAM, I was curious whether it could show GIWAXS images on the log scale, using the help of my AI buddy Claude Sonnet 5.5 low. One thing led to another, and before I knew it, Claude had put together the GUI. So what, I thought, let's add some wild calculations and see whether Claude and the Raspberry Pi 5 could handle it. Yes, wow, and that at lightning speed! Only using the limited Debian python distribution with numpy and tkinter. And I added matplotlib, which also gave me PIL and scipy bundled with it. Cool!

Conclusion: Python code has amazing performance, even on this limited hardware. But coming from the Matlab/Scilab world, the actual coding is mostly a mystery to me. But that's what friends are for...

Long story short, in the course of the day I kept adding bits and pieces, feeding claude with key pieces of my Scilab code. The GUI is getting there. And full indexGIXS-3 capabilities. With another weekend's work, porting more features and more finetuning of the GUI, the outcome started to look appealing and functional. The image indexGIXS.png shows a screenshot. The parameters in the indexGIXS.py GUI are predefined to process the TIFF example file. Just Load the image and Calc the spot positions.

The functionality of the python version is very similar to indexGIXS-3, check out the documentation there. The detector menu was not needed, since all 16-bit and 32-bit monochromic TIFF formats are already supported by PIL. I had claude add a module to read ESRF Data Files (EDF) including the setup information from the metadata header, as based on my Scilab-3 script. In addition Advanced Lightsource GB files are supported for the Pilatus 1M and 2M detectors at their GISAXS beamline. Some obsolete CHESS detectors aren't supported any more, though. But, based on my collection of test data that indexGIXS users have sent me over the years: So far, so good!
