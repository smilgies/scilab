indexGIXS-3C

Version 3C with scilab-2027.0.0 finally overcomes the issue with running the software under MS Windows 11 Enterprise!

The problem with the program crashing under scilab-2026.1.0 and Win 11 Enterprise remains, though, and these versions won't be supported any more in the future. scilab-2023.1.0 still runs version 3C but be will be deprecated in the future, so that inconsistencies between the 2023 and 2027 versions no longer clutter up the code.

Some tweaks and fixes to the GUI building were helpful to get the program to load more efficiently. The simulation mode for generating GIXS patterns without prior loading of an image is now explicitly supported as a new detector option "simulate".
Parameters are preset to reproduce the images in Figure 4 of the "Power of Indexing" paper.
